工作原理

它待在菜单栏里，帮你把磁盘收拾得井井有条。

1. 找出闲置项目

它读取每个项目自身的文件来判断技术栈，再计算其中可重新生成的构建产物有多大。最近动过的项目不会被处理。

2. 把它们收起

点一下即可，也可以交给自动模式：每当可用空间低于你的目标，它就会自动处理。闲置最久的项目最先收起。

3. 唤醒它们

重新打开一个旧项目时，Mothball 会察觉到。唤醒时，它会为该项目的技术栈运行相应的恢复命令： npm install, flutter pub get, pod install.

这些都可以放心收起。

这里的每个文件夹都能用一条命令重新构建。只有当它所在的项目能证明自己是哪类项目时，Mothball 才会处理它。

安全是设计出来的

足够谨慎，可以放心一直开着。

让你提心吊胆的清理工具，你永远不会去用。Mothball 宁可跳过一个文件夹，也不会去猜。

  • 绝不改动 git 跟踪的任何内容。 只要提交过，就是你的。
  • 绝不只凭文件夹名称判断。 名为 build 的文件夹，只有在它所在的项目表明它是构建产物时才算。
  • 有未提交的改动，就视为活跃项目。 正在修改中的项目会被跳过。
  • 移动前再检查一遍。 如果扫描之后有任何变化，它就会停下，不再移动。
  • 只移到废纸篓或回收站，绝不直接删除。 每次移动都有记录，用 .mothballignore 可以保留你想保留的任何内容。
